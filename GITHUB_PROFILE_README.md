## How I think about AI products

I am especially interested in systems where AI does more than generate text.

When software can take actions on a user's behalf, the design questions become:

- What is the system doing?
- What evidence is it using?
- What is it allowed to do?
- How does the user interrupt or recover?
- When should automation stop?
- What requires human approval?

That intersection of **experience design and system behavior** is where I do my best work.
