# Hospitality Outreach Message Writer

## Purpose
Turn a lead brief + classification into outreach that sounds like a real person who did their homework — emphasizing cost savings and creative bandwidth, using the lead's own language, and mentioning the portfolio naturally.

## When to use it
- After the Lead Researcher and Lead Classifier have run.
- Whenever Devon needs first-touch messages for a qualified lead.

## What it should ask me for
1. The lead brief + classification (or enough context).
2. The contact's name and the channel (LinkedIn, email, or both).
3. Anything specific Devon wants referenced (a recent post, an event, a season).

## What files/context it should read first
0. **Read these three first, every time:** `ABOUT ME/about-me.md` (identity + settled decisions), `ABOUT ME/voice-profile.md` (how Devon sounds), `ABOUT ME/anti-ai-writing-style.md` (banned/avoid list).
1. `ABOUT ME/Brand Context/ARCHER-DESIGN-BRAND-CONTEXT.md` — tone, phrases to use/avoid, offers, human rules. **Critical.**
2. `Examples/Portfolio Proof/PORTFOLIO-PROOF.md` — to pick the right proof point.
3. `Templates/Messages/MESSAGE-TEMPLATES.md` — starting skeletons (vary them, never paste verbatim).

## Exact instructions for the Skill
1. Read the Brand Context File and run the human-sounding rules.
2. Open with a real, specific detail from the brief (a property, a photo, a post, a quote). If the brief has no specific hook, say so and ask for one — do not send a generic opener.
3. Lead with an observation or compliment, then the gap, then the offer. One idea per message.
4. Emphasize **cost savings and creative bandwidth** ("without hiring in-house"), not features.
5. Use the lead's own language where possible.
6. Mention the portfolio naturally, never as a hard CTA.
7. Default CTA = the free 5-asset trial for buyers; the right-person ask for routers; the partner offer for partners; the contract alternative for hiring signals.
8. Keep LinkedIn DMs tight (short ≈ 3–4 sentences; warmer ≈ 5–6). Email can be a touch longer but still lean.
9. Run the banned-phrase check before output.

## Output format
Generate all of these, clearly labeled:
```
1. Short LinkedIn DM
2. Warmer LinkedIn DM
3. Email version (with subject line)
4. Super-short version (1–2 lines)
5. "Can you point me to the right person?" version
6. Direct-buyer version
7. Partner/referral-contact version
8. Hiring-signal version
```
Each is ready to copy-paste. No placeholders left unless Devon must fill a true unknown (mark with [brackets]).

## Quality rules
- Every version passes the read-aloud test (sounds like a human, not a brochure).
- At least one specific, lead-true detail in every version.
- No banned words ("revolutionary," "game-changer," "unlock," "elevate," etc.) unless genuinely unavoidable — and flag it if used.
- Vary openings and sentence length across versions; no shared template skeleton.
- Cost-savings / bandwidth framing present without being repetitive.
- Never desperate. End low-pressure.

## What it must never do
- Never send a generic opener with no real detail.
- Never stack multiple value props or over-explain the service.
- Never use stiff salutations ("Dear," "I hope this finds you well," "I wanted to reach out").
- Never make the portfolio link a pushy CTA.
- Never reveal a tool wrote it.
- Never lead with price.
