# Archer Design — Usage Examples (per Skill)

> One quick example for invoking each Skill. Just paste the lead/context and name the Skill.

## Hospitality Lead Researcher
> "Run the lead researcher on https://www.examplehotel.com — found them on a cold list."
→ Returns a full lead brief (summary, category, fit, pain points, quotes, angle, offer, priority, tags, next action).

## Lead Classifier
> "Classify this lead: a recruiter posting a 'Social Media Coordinator, hotel group' role."
→ Returns lead type (Hiring signal) + angle, offer, CTA, what not to say.

## Hospitality Outreach Message Writer
> "Write outreach for the Indigo-style boutique hotel brief, direct buyer, LinkedIn + email."
→ Returns 8 labeled versions (short DM, warm DM, email, super-short, right-person, buyer, partner, hiring).

## Hospitality Follow-Up Generator
> "Lead replied 'I'll pass this along to our marketing team.' Follow-up?"
→ Returns LinkedIn + email reply, next action, CRM status, timing.

## 7-Day / 5-Asset Trial Builder
> "Build the trial for a spa that's interested — summer wellness season coming up."
→ Returns trial scope, inclusions/exclusions, ask, timeline, transition, propose message + email + post-delivery follow-up.

## Partner / Referral Offer Builder
> "Build a partner offer for a hotel sales consultant I met."
→ Returns short + warm partner messages, email, commission explainer, vetting questions, agreement outline, CRM fields.

## Proposal & Package Generator
> "Lead's a 3-property select-service group, interested after the trial. Proposal?"
→ Returns recommended packages with deliverables, output, savings framing, placeholder pricing, short message.

## CRM Update Assistant
> "[paste reply] — what do I log?"
→ Returns every CRM field mapped to schema values + follow-up date + what to offer next.

## LinkedIn Comment / Visibility Assistant
> "Comment on a GM's post about how hard it is to keep their hotel's Instagram active."
→ Returns thoughtful / shorter / light-services / no-pitch comments + follow-up DM.

## Job Signal Hijack Assistant
> "Hotel group posted 'Social Media & Content Coordinator' — apply and pitch the contract option."
→ Returns fit score, resume positioning, cover letter, recruiter DM, contract-alternative message, tags, follow-up plan.

## Context Loader
> "Load context for a Hampton property GM I want to message."
→ Returns lead type, angle, offer, tone, checkpoints (cost-savings/trial/right-person/portfolio/proof), next action.

## Socratic Task Interviewer
> "Build me a pricing strategy for the retainer packages."
→ Asks 5–10 specific questions, summarizes answers, proposes a plan, builds only after approval.

## Fresh Session Handoff Writer
> "Session's getting long — write a handoff for the CRM build."
→ Returns full handoff + a paste-ready prompt for a fresh session.
