# Island Hospitality — Thought-Starter (public info only)

> Rules: no overclaiming, no invented facts. Island is framed as what it publicly
> is: a multi-property hospitality management company with recognizable hotel
> brands. Verify every specific (portfolio size, brands, names) before any send.

## Framing
Island Hospitality manages a large portfolio of branded hotels across multiple markets. At that scale, the creative question isn't "can each property post?" — it's "does the portfolio read like one company?" That's a corporate-level asset: owner relations, brand audits, and the next management contract all see it.

## The five angles (use one per touch, not all at once)

1. **Portfolio consistency.** "With a portfolio Island's size, every property posting differently makes the company look smaller than it is. Group-level visual consistency with property-level flexibility is exactly what an outside creative system holds."
2. **Digital marketing alignment.** "Corporate digital sets strategy; properties execute unevenly. The gap is production bandwidth, not direction. A creative system plugs into the existing strategy rather than replacing it."
3. **Property-level creative bandwidth.** "No single select-service property justifies a creative hire — and all of them need consistent output. Fixed-fee coverage across a set of properties is the math that works at management-company scale."
4. **F&B / events / local campaigns.** "The properties with restaurants, bars, and event space have local revenue that brand templates don't promote. That's the layer we cover: menu features, event pushes, seasonal campaigns, brand-standard-aware."
5. **Start with 3–5 properties.** "Not a portfolio pitch — a 3–5 property pilot. One month, one approval workflow, one invoice. Island judges real output on real properties, then expansion is an evidence decision."

## First-touch draft (question-led, manual send)
"Hi [First] — question about how Island handles property-level creative across the portfolio. Most management companies I talk to either centralize it thin or let each property improvise. I run a fixed-fee creative system for hotel groups (Indigo Pittsburgh, Hampton properties, hotel F&B) — curious which camp Island's in?"

## What to prepare before any call
- Screenshots of 4–6 Island-managed property feeds, side by side (the consistency story tells itself)
- One before/after matched to a property type they actually manage
- The 3–5 property pilot slide with [3–5 plausible properties] pre-filled — let them correct the list
