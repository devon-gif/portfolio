# CLAUDE OUTPUTS

> All final deliverables produced by the Skills land here.

## Naming convention
```
archer_hospitality_[output-type]_[lead-or-company]_v1.md
```

### Examples
- `archer_hospitality_lead-brief_indigo-pittsburgh_v1.md`
- `archer_hospitality_outreach_hampton-downtown_v1.md`
- `archer_hospitality_trial-offer_serenity-spa_v1.md`
- `archer_hospitality_proposal_midwest-hotel-group_v1.md`
- `archer_hospitality_partner-offer_jane-recruiter_v1.md`
- `archer_hospitality_followup_lakeside-resort_v1.md`
- `archer_hospitality_handoff_crm-build_v1.md`

### Output types
`lead-brief` · `classification` · `outreach` · `followup` · `trial-offer` · `proposal` · `partner-offer` · `crm-update` · `comment` · `job-signal` · `handoff` · `context-load`

## Versioning
Bump `_v1` → `_v2` when revising the same deliverable. Keep prior versions for reference.
