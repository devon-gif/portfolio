## What this repository demonstrates

This is more than a static portfolio. It is a working Next.js platform used to design, prototype and ship:

- UX/UI and interactive product work
- hospitality and brand campaign systems
- motion-rich landing experiences
- private pitch and client presentation pages
- case studies and project storytelling
- reusable marketing components
- lead / contact workflows
- API-backed forms and business tooling
- responsive design systems

The project reflects how I prefer to work: **design the experience, build the real thing, test it in context, and iterate from actual behavior.**

## Selected themes

### Design → code
Interfaces are built as functional experiences rather than stopping at static comps.

### Creative systems
Reusable components and structured content make it possible to produce many different campaign, client and product experiences without rebuilding the visual language each time.

### Rapid prototyping
The repository is also a working environment for testing new product and interaction ideas quickly before deciding what deserves deeper investment.

### Storytelling
Technical products still need clarity. Much of the work here focuses on making complex ideas understandable through hierarchy, motion, visual design and interaction.
