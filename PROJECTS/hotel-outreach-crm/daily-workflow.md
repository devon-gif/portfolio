# Daily Workflow — Archer Design Outreach

> The recommended daily operating rhythm using the Skills. Canonical workflow file.

## Start of day (10 min) — load context
1. Skim `ABOUT ME/about-me.md`, `voice-profile.md`, `anti-ai-writing-style.md` (or let the **Context Loader** Skill do it).
2. Open `PROJECTS/hotel-outreach-crm/best-performing-messages.md` to keep what's working top of mind.
3. Check CRM for today's follow-up dates.

## Block 1 — New leads (research + classify)
For each new lead:
1. **Hospitality Lead Researcher** → lead brief (save to `lead-research-notes.md`).
2. **Lead Classifier** → lead type.
3. **CRM Update Assistant** → log it.

## Block 2 — Outreach (qualified leads)
1. **Context Loader** → confirm angle/offer/proof for the lead.
2. **Hospitality Outreach Message Writer** → generate messages.
3. Send. Log to CRM (status → Contacted, set follow-up date).

## Block 3 — Follow-ups (replies + due bumps)
1. **Hospitality Follow-Up Generator** for each reply / due follow-up.
2. Route hot replies to **Trial Builder** or **Proposal Generator**.
3. **CRM Update Assistant** → update every touched lead.

## Block 4 — Visibility (15–20 min)
1. **LinkedIn Comment/Visibility Assistant** on 3–5 relevant hospitality posts.
2. **Job Signal Hijack Assistant** on any relevant job posts found.

## Block 5 — Partners (weekly, not daily)
1. **Partner/Referral Offer Builder** for new partner prospects.
2. Track in `partner-offer.md` + CRM partner fields.

## End of day (5 min)
- Confirm every touched lead has a status + next follow-up date.
- Add any winning message to `best-performing-messages.md`.
- If the session/context got long, run **Fresh Session Handoff Writer**.

## Weekly
- Review priority scores + tone (Day 4 tuning principles).
- Update `objection-responses.md` and `best-performing-messages.md` with new learnings.
