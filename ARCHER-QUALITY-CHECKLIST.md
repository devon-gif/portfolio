# Archer Design — Quality Checklist

> Run this on any message/output before it ships. If it fails any item, rewrite. Goal: output that never sounds generic or AI-written.

## The non-negotiables (every message)
- [ ] Opens with a **real, specific detail** about this lead/property — not a generic intro.
- [ ] **One idea** only. No stacked value props.
- [ ] **Cost savings / creative bandwidth** framing is present (when relevant).
- [ ] Uses the **lead's own language** where possible.
- [ ] Proof mentioned **naturally** (1 client + maybe 1 stat), never a dump.
- [ ] Portfolio link feels natural, not a hard CTA.
- [ ] **Low-pressure close** with an easy out.
- [ ] LinkedIn DM is **3–6 sentences**.

## Banned-phrase scan (must be zero)
- [ ] No: game-changer, revolutionary, unlock, elevate, delve, tapestry, synergy, robust, seamless, "transform your business," "in today's fast-paced world."
- [ ] No: "I hope this finds you well," "I wanted to reach out," "pick your brain," "Dear [Name]."
- [ ] "leverage" only if plainly natural (else use "use").

## AI-tell scan
- [ ] Sentences vary in length; openings aren't all the same.
- [ ] No tidy "In conclusion / I hope this helps" wrapper.
- [ ] No parallel benefit lists.
- [ ] Not summarizing the lead's situation back to them mechanically.
- [ ] **Read-aloud test passed** — sounds like a person texting a peer.

## Accuracy
- [ ] Every claim about the lead is real or labeled an inference.
- [ ] No invented properties, names, quotes, or stats.
- [ ] CRM values come from `/crm/CRM-SCHEMA.md`.
- [ ] Pricing is clearly placeholder until confirmed.

## Fit + consistency
- [ ] Offer matches the lead type (no trial to a partner, no "want to hire me?" to a hiring signal — use the contract alternative).
- [ ] Bad-fit leads scored low, not forced.
- [ ] Tone matches `voice-profile.md`.

## Doesn't sound desperate
- [ ] Confident, not needy.
- [ ] No more than 2 no-response bumps.
- [ ] No fake urgency.
