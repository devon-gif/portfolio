# Archer Design — 5-Day Implementation Plan

> How to stand up and start using the system. Each day builds on the last.

## Day 1 — Foundation + first outreach
- [x] Build the **Brand Context File** (`ABOUT ME/Brand Context/`).
- [x] Build the persistent context (`about-me.md`, `voice-profile.md`, `anti-ai-writing-style.md`).
- [x] Build the **Lead Researcher** and **Outreach Writer** Skills.
- **Do:** run the Researcher on 2–3 real leads, write outreach with the Writer, send.

## Day 2 — Follow-up + CRM + trial
- [x] Build the **Follow-Up Generator**, **CRM Update Assistant**, and **7-Day Trial Builder**.
- **Do:** set up the CRM using `/crm/CRM-SCHEMA.md`. Log Day 1 leads. Handle any replies.

## Day 3 — Partner + proposal + visibility
- [x] Build the **Partner Offer Builder**, **Proposal Generator**, and **LinkedIn Comment Assistant**.
- **Do:** message 2 potential partners. Comment on 5 hospitality posts. Draft a proposal for any warm lead.

## Day 4 — Test + tune
- **Do:** run the full pipeline on **10 real leads**.
- Improve the **priority scoring** rubric based on what actually converts.
- Tighten **tone rules**: log winners in `best-performing-messages.md`, losers too.
- Add real objections + responses to `objection-responses.md`.

## Day 5 — Operationalize
- **Do:** fold the Skills into the daily CRM workflow (`PROJECTS/hotel-outreach-crm/daily-workflow.md`).
- Set follow-up dates on every active lead.
- Consider a scheduled daily reminder to run the workflow.
- Use **Context Loader** before every outreach, **Socratic Task Interviewer** before any big build, **Fresh Session Handoff Writer** when sessions get long.

## Ongoing
- Weekly: review scores + tone, update best-performing/objection files.
- Treat context files as living documents — the system compounds as you feed it real results.
