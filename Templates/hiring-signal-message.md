# Template — Hiring Signal Message

> Skeleton only. Read `voice-profile.md` + `anti-ai-writing-style.md` first. Core angle = contract/retainer as an alternative to full-time headcount.

## LinkedIn (to recruiter / hiring manager)
> Hi [Name] — saw [Company] is hiring for [role]. Happy to apply formally, but I also wanted to flag the contract/retainer option in case flexible creative support fits better than adding full-time headcount. I already do this for a few hotels — portfolio here: https://devonarcher.framer.website/

## Contract-alternative (standalone)
> Hey [Name] — noticed the [role] opening at [Company]. Whatever you decide on the hire, I wanted to put the flexible option on the table: I provide ongoing creative (design, motion, social) as an outside partner, so you get the output without the salary/benefits/recruiting overhead. Could cover the gap now or run alongside a hire. Want me to send a few free samples?

## Email
> **Subject:** [role] at [Company] — formal application + a flexible alternative
> Hi [Name],
> I'd like to apply for [role] — but I also run an outside creative service for hotels, and wanted to flag that in case flexible contract support would fit better than (or alongside) a full-time hire. It covers the same creative output without the headcount cost.
> Portfolio: https://devonarcher.framer.website/ — happy to send 5 free sample pieces for [Company] so you can see the work. — Devon

## Notes
Never disparage hiring. Frame as cost savings + flexibility. Don't sound desperate for the job.
